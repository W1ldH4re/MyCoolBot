# 😈 Emoji Game Bot

Telegram-бот для игры между двумя пользователями в приватной комнате.

Игрок создаёт комнату, выбирает категорию игры и приглашает второго участника по коду комнаты. После подключения начинается игровая сессия с заданиями и выбором смайлов.

---

## 🚀 Возможности

* Создание приватных комнат
* Подключение второго игрока по коду
* Система игровых категорий
* Система очередности ходов
* Смайлы с заданиями
* FSM состояния пользователей
* Поддержка Aiogram 3.x
* Готовность к подключению SQLite/PostgreSQL

## 📦 Установка

### 1. Клонирование проекта

```bash
git clone https://github.com/yourname/emoji_game_bot.git

cd emoji_game_bot
```

### 2. Создание виртуального окружения

Windows:

```bash
python -m venv venv
```

Linux:

```bash
python3 -m venv venv
```

Активация:

Windows:

```bash
venv\Scripts\activate
```

Linux:

```bash
source venv/bin/activate
```

---

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Или вручную:

```bash
pip install aiogram aiohttp
```

---

## ⚙️ Настройка

Открой файл:

```text
config.py
```

Укажи токен Telegram-бота:

```python
TOKEN = "YOUR_BOT_TOKEN"
```

Если используется HTTP-прокси:

```python
PROXY_URL = "http://user:password@host:port"
```

---

## 🤖 Создание бота

1. Открой Telegram
2. Найди @BotFather
3. Выполни команду:

```text
/newbot
```

4. Получи токен
5. Вставь токен в `config.py`

---

## ▶️ Запуск

```bash
python bot.py
```

После успешного запуска в консоли должно появиться:

```text
Бот запускается...
Бот запущен...
```

## 🎮 Игровой процесс

### Создание комнаты

1. Нажать:

```text
🆕 Создать комнату
```

2. Получить код комнаты:

```text
5821
```

3. Передать код второму игроку.

---

### Подключение к комнате

1. Нажать:

```text
🔑 Войти в комнату
```

2. Ввести код комнаты.

3. После подключения начинается игра.

## ⚠️ Важно

Текущая версия хранит комнаты в оперативной памяти:

```python
rooms = {}
```

После перезапуска бота все комнаты будут удалены.

Для продакшн-использования рекомендуется подключить базу данных.
